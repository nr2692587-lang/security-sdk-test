# Chemal & Gegg Educational Examples

This document provides simple, original educational examples featuring **Chemal** and **Gegg**. Each example is self-contained and designed to teach a practical communication or problem-solving skill.

## Example 1: Clarifying Ambiguous Instructions

### Scenario
Chemal says: "Please organize these notes soon."

Gegg replies:
> "Happy to help. To make sure I do this correctly, do you want them sorted by date, topic, or priority—and when is your deadline?"

### What this teaches
- **Ask clarifying questions** when a request is vague.
- **Confirm success criteria** (format + deadline) before starting work.

## Example 2: Giving Constructive Feedback

### Scenario
Gegg shares a draft lesson plan with Chemal.

Chemal responds:
> "I like your clear step-by-step flow. One improvement: add a short quiz after section two so learners can check understanding before moving on."

Gegg replies:
> "Great idea. I’ll add a 3-question quiz and keep it focused on the section’s key concepts."

### What this teaches
- **Balance praise with actionable suggestions**.
- **Turn feedback into specific next steps**.

## Example 3: De-escalating a Disagreement

### Scenario
Chemal and Gegg disagree about which topic to teach first.

Chemal says:
> "We both want learners to succeed. Let’s list both options, compare expected difficulty, and choose the one with lower entry barriers."

Gegg agrees:
> "That works. We can also note what prior knowledge each option requires."

### What this teaches
- **Shift from positions to shared goals**.
- **Use objective criteria** to make decisions calmly.
